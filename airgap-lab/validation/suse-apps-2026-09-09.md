## Storage correction found by the run

The local-path provisioner initially created helper pods using its default
Docker Hub `busybox` image. After isolation, these helpers could not pull their
image, leaving the application PVCs Pending.

The lab now pins the helper template to the already mirrored
`registry.suse.com/bci/bci-busybox:15.7` image and reloads the provisioner when
the template changes. The same role runs during connected node configuration
and before SUSE application deployment when extending an existing lab.
Provisioning recovered with isolation still enabled. A second role run changed
nothing on either target. The updated `suse-apps` phase also passed on rerun;
only the saved evidence files changed.
